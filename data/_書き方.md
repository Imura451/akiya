# 物件の書き方（data/properties.json）

JSON というファイルには、注記を書き込めない決まりがあります。
そのため、項目の説明はこのファイルにまとめています。

## 1件分の例

```json
{
  "id": "obu-002",
  "published": true,
  "type": "house",
  "tags": ["staffHousing"],
  "city": {
    "ja": "愛知県大府市",
    "vi": "Thành phố Obu, tỉnh Aichi",
    "en": "Obu City, Aichi"
  },
  "area": "aichi",
  "price": 3800000,
  "landArea": 120.5,
  "buildingArea": 85.2,
  "builtYear": 1978,
  "layout": "4DK",
  "structure": { "ja": "木造2階建て", "vi": "Nhà gỗ 2 tầng", "en": "2-story wooden house" },
  "station":   { "ja": "JR東海道本線「共和」駅 徒歩15分", "vi": "…", "en": "…" },
  "yieldPercent": 9.5,
  "yieldBasis": { "ja": "想定家賃 月3万円で、満室の場合の表面利回り", "vi": "…", "en": "…" },
  "status":  { "ja": "空き家", "vi": "Nhà trống", "en": "Vacant" },
  "rebuild": { "ja": "再建築可（幅4mの道路に接しています）", "vi": "…", "en": "…" },
  "comment": { "ja": "…", "vi": "…", "en": "…" },
  "photos": ["01.jpg", "02.jpg", "03.jpg"],
  "mapQuery": "愛知県大府市",
  "videoTalk": "XXXXXXXXXXX",
  "videoVisit": "YYYYYYYYYYY"
}
```

## 項目の説明

| 項目 | 書くこと | 例 |
|---|---|---|
| `id` | 物件の名前。**半角の小文字・数字・ハイフンだけ**。ほかの物件と重ならないように。URLと写真のフォルダ名になります | `obu-002` |
| `published` | 載せるなら `true`、一時的に隠すなら `false` | `true` |
| `sample` | 架空のサンプルなら `true`。本物の物件には書きません | — |
| `type` | **種別**。下の表のどれか1つ | `house` |
| `tags` | **用途の印**。下の表から、当てはまるものをいくつでも。無ければ `[]` | `["staffHousing"]` |
| `city` | 所在地（市町村まで）。3言語で | 上の例 |
| `area` | 絞り込み用の地域。`aichi` `mie` `gifu` `shizuoka` のどれか | `aichi` |
| `price` | 価格（円）。**数字だけ**。カンマや「万」は付けません | `3800000` |
| `landArea` | 土地の面積（㎡）。数字だけ | `120.5` |
| `buildingArea` | 建物の面積（㎡）。**土地だけの物件は `null`**（その行が出なくなります） | `85.2` |
| `builtYear` | 建てた年（西暦）。築年数は自動で計算します。土地だけなら `null` | `1978` |
| `layout` | 間取り。無ければ `""` | `4DK` |
| `structure` | 構造。3言語で。無ければ `""` | |
| `station` | 最寄りの交通。3言語で | |
| `yieldPercent` | 想定利回り（%）。数字だけ。出さないなら `null` | `9.5` |
| `yieldBasis` | **利回りの根拠**。想定家賃など、何から計算したかを書きます | |
| `status` | 現況（空き家、残置物あり、更地 など） | |
| `rebuild` | 再建築できるか、接している道路 | |
| `comment` | 管理人からのひとこと | |
| `photos` | 写真のファイル名。**1枚目が一覧の表紙**になります | `["01.jpg"]` |
| `mapQuery` | 地図で表示する場所。住所の番地までは書かず、町名くらいまでがよいです | `愛知県大府市` |
| `videoTalk` | **管理人2人の解説**の動画ID（`https://youtu.be/XXXX` の `XXXX`）。無ければ `""` | |
| `videoVisit` | **現地調査の記録**の動画ID。**入れると、一覧に「現地調査済み」の印が付きます** | |

## 種別（`type`）

| 書く言葉 | 表示 |
|---|---|
| `house` | 戸建て |
| `mansion` | マンション |
| `land` | 土地 |
| `warehouse` | 倉庫 |
| `shop` | 店舗 |
| `office` | 事務所 |

**載っている物件の種別が2つ以上になると、一覧に「種別」の絞り込みが自動で出ます。**

種別を増やしたいときは、`data/settings.json` の `types` に言葉を足し、3つの lang ファイルの `props.types` に見出しを足します。

## 用途の印（`tags`）

| 書く言葉 | 表示 |
|---|---|
| `staffHousing` | 外国人材用住宅 |

**1件でも印が付くと、一覧に「用途」の絞り込みが出ます。** 種別とは別に付けられるので、「戸建てで、外国人材用住宅にも向く」のように書けます。

## 価格帯

一覧の「価格」の区切りは、`data/settings.json` の `priceBands` で決めています。

```json
{ "key": "300_1000", "min": 3000001, "max": 10000000 }
```

`min` 以上 `max` 以下の物件が、その区切りに入ります。`max` を `null` にすると上限なしです。
見出しの文字は、3つの lang ファイルの `props.priceLabels` にあります。区切りを変えたら、見出しも合わせて直してください。

## 3言語の書き方

`{"ja": "…", "vi": "…", "en": "…"}` の形で書きます。
**ベトナム語や英語が空でも構いません。** その場合は、英語か日本語で代わりに表示されます。

## 写真の置き場所

```
assets/properties/obu-002/01.jpg
assets/properties/obu-002/02.jpg
```

フォルダ名は `id` と同じにします。写真が見つからないと、公開の仕組みが知らせます。

## 利回りについて

**根拠を示せない利回りは載せません。** `yieldBasis` に、想定家賃と、満室の場合かどうかを必ず書いてください。
物件の広告は、提携の宅建業者の広告として載せる形になります。表示のしかたは提携業者に確認してください。

## 撮影と掲載の前に確認すること

- **ほかの会社のサイトの画面や写真を、動画に映さないでください。** 写真には撮った人の権利があります。情報は自分たちの言葉で話し、写真は自分たちで撮ったものを使います
- **ほかの会社が扱っている物件を載せるときは、提携の宅建業者を通じて、その会社の承諾を取ってください。** 他社の物件を広告するには、元の業者の承諾が必要になるのが一般的です
- **現地で撮るときは、近所の家や人、車のナンバーが映らないように**するか、あとでぼかしてください。室内を撮るときは、売主の許可を取ってください
