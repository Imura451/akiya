# 空き家の管理人（Người Quản Lý Nhà / The Akiya Caretaker）

ベトナム在住の投資家に向けた、日本の不動産の情報サイトです。築古戸建て（空き家）を中心に、マンション・土地・店舗・倉庫・事務所も扱います。
日本語・ベトナム語・英語の3言語で表示します。

運営：株式会社Minobordo（ガイコクジンコネクト）

## 1. 文章を直す（Huong さん向け）

`lang/vi.json` をメモ帳などで開きます。

```json
"heroTitle": "Sở hữu nhà tại Nhật Bản, từ Việt Nam.",
```

**左側（`"heroTitle"`）は変えずに、右側の `"…"` の中だけを直してください。**

気をつけること

- 文章の中で `"` を使いたいときは `\"` と書きます
- 行の最後の `,`（半角のカンマ）を消さないでください。ただし、`}` の直前の行にはカンマを付けません
- 保存するときの文字コードは **UTF-8** にしてください（メモ帳なら「名前を付けて保存」の下で選べます）

書き間違いがあると、公開の仕組みが **何行目の何文字目がおかしいか** を日本語で知らせます。

**ベトナム語に無い項目は、英語か日本語で代わりに表示されます。** 翻訳が途中でも、ページが壊れることはありません。

## 2. 物件を足す（井村さん向け）

### 手順

1. `data/properties.json` を開きます
2. いちばん上の物件（`{` から `},` まで）をまるごとコピーして、すぐ下に貼り付けます
3. 貼り付けたほうの中身を、新しい物件に書き換えます
4. `id` を、ほかと重ならない名前にします（例：`obu-002`。**半角の小文字・数字・ハイフンだけ**）
5. 写真を `assets/properties/（idと同じ名前のフォルダ）/` に入れ、`photos` にファイル名を書きます
6. `type`（種別）と `tags`（用途の印）を書きます
7. 動画があれば、`videoTalk`（管理人2人の解説）と `videoVisit`（現地調査の記録）に動画IDを書きます。**現地調査の動画を入れると、一覧に「現地調査済み」の印が付きます**

項目ごとの書き方は `data/_書き方.md` にあります。

### サンプルの物件について

いま入っている4件（`sample-01`〜`04`）は、**表示を確かめるための架空の物件**です。`sample-04` は土地の表示を確かめるためのものです。
「サンプル」の印が付き、検索エンジンにも載りません。

本番の物件を載せたら、`data/settings.json` の

```json
"showSamples": true,
```

を `false` にしてください。サンプルが一覧から消えます。

## 3. 設定を変える（`data/settings.json`）

| 項目 | 中身 | いま |
|---|---|---|
| `partner` | 提携の宅建業者の商号と免許番号 | **未設定**（「確認中」と表示） |
| `exchange` | 1円が何ドンか、その日付 | **未設定**（ドンの金額を出していません） |
| `messengers` | Zalo・Messenger・WhatsApp・LINE の URL | LINE だけ設定済み |
| `videos` | トップと運営者ページの動画ID | **未設定**（写真と文章を表示） |
| `showSamples` | サンプル物件を出すかどうか | `true` |
| `priceBands` | 一覧の「価格」の区切り（円） | 300万・1,000万・3,000万で区切り |
| `types` | 種別の並び（戸建て・マンション・土地・倉庫・店舗・事務所） | 6種類 |
| `tags` | 用途の印の並び（外国人材用住宅） | 1種類 |

**空の項目は、ページに出しません。** リンク切れや、中身の無いボタンができないようにしています。

### 為替レートの入れ方

```json
"exchange": {
  "jpyToVnd": 170,
  "asOf": "2026年9月",
```

`jpyToVnd` に「1円が何ドンか」を数字で、`asOf` にその時点を入れます。
すべての物件のドンでの金額が、この1つの数字から計算されます。ページには「参考値」と添えて出します。

## 4. 手元で確認する

1. このフォルダで、次を実行します

   ```
   node build.js
   ```

2. `docs/` の中にページができます
3. 確認用のサーバーを立てて、ブラウザで `http://localhost:8766/` を開きます

   ```
   python -m http.server 8766 --directory docs
   ```

`docs/index.html` を直接ダブルクリックしても開けますが、言語の自動判定など一部の動きは、サーバー経由でないと確かめられません。

## 5. ネットに公開する（GitHub Pages・無料）

人材バンクと同じ仕組みです。

### 最初の1回だけ

1. GitHub に、`akiya` という名前で保存先（リポジトリ）を作ります（Public）
2. このフォルダを、その保存先につなぎます
3. GitHub の Settings → Pages → Source を **GitHub Actions** にします

### 2回目から

**ファイルを直して GitHub に送るだけで、数分後に自動で公開されます。**
`docs/` は GitHub 側で作り直すので、送る必要はありません。

公開される URL：**https://imura451.github.io/akiya/**

独自ドメインを取得したら、`data/settings.json` の `siteUrl` を書き換えます。

## 7. まだ公開していないもの

**お金の流れ（二国間の送金・支払いの代行）** は、専門家の確認が取れるまで公開しません。
下書きは `_非公開/お金の流れ_下書き.html` にあります。専門家に見ていただくときに使ってください。

確認が取れるまでのあいだ、サイトでは次のように書いています。

- 取得の流れ 06「代金のお支払い」… お支払いの手順は、物件ごとに個別にご案内します
- サービス一覧 … 送金・支払いの代行は載せていません
- 固定資産税 … 弊社が「納税管理人」として手続きします
